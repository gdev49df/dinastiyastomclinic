# Dinastiya Stom Clinic

Сайт стоматологии Dinastiya Stom Clinic (Астана, пр. Туран 34Б). Чистые HTML, CSS и JS, без сборки.

## Структура

- `index.html` — главная страница
- `css/style.css` — стили
- `js/data.js` — контакты, ссылки, список врачей (имена и должности заполняются здесь)
- `js/main.js` — меню, появление блоков, форма заявки в WhatsApp
- `img/` — логотип и фотографии

## Запуск локально

```
python3 -m http.server 8000
```

Открыть http://localhost:8000

## Что заполнить

- `js/data.js`, массив `team`: поля `name` и `role` у каждого врача (пока пустые, подпись скрыта)
- `js/data.js`, поле `hours`: график работы
